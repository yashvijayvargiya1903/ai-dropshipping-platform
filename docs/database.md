# Database Model

Core entities:
User, CustomerProfile, Product, ProductVariant, ProductMedia, Category, Supplier, SupplierProduct, PriceRule, Inventory, Cart, Order, OrderItem, Payment, Refund, ReturnRequest, ExchangeRequest, Shipment, TrackingEvent, SupplierOrder, Notification, AutomationRun, SupportConversation, AuditLog.

All financial and operational changes must be auditable. Secrets must be stored outside source control.
