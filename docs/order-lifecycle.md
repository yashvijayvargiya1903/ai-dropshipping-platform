# Order Lifecycle

PENDING_PAYMENT → PAID / COD_CONFIRMED → FULFILLMENT_PENDING → SUPPLIER_SUBMITTED → SUPPLIER_CONFIRMED → SHIPPED → IN_TRANSIT → OUT_FOR_DELIVERY → DELIVERED.

Exception states:
CANCEL_REQUESTED, CANCELLED, RETURN_REQUESTED, RETURN_IN_TRANSIT, RETURNED, EXCHANGE_REQUESTED, EXCHANGED, REFUND_PENDING, REFUNDED, SUPPLIER_ACTION_REQUIRED, MANUAL_REVIEW.

Every transition records actor, timestamp, source and metadata.
