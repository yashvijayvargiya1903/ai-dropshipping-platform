# Pricing

Default margin rule for positive supplier cost:

margin = 100 × ceil(cost / 300)

Examples:
- ₹0–₹300 → +₹100
- ₹301–₹600 → +₹200
- ₹601–₹900 → +₹300

The owner can override the selling price per product.

Admin should display supplier cost, automatic margin, calculated price, override and effective selling price.
